# 📊 AI DASHBOARD

An intelligent, interactive executive data dashboard built with **React** for the frontend and **FastAPI + OpenAI** for the backend engine. 

Upload any CSV or JSON dataset to instantly generate dynamic KPI cards, interactive slicers, multiple visualization charts, and a detailed 20-point AI-generated analytical explanation report.

---

## ✨ Features

- 📁 **Universal Dataset Ingestion**: Upload any CSV or JSON file without manual schema configuration.
- ⚡ **Dynamic Slicer & Filter Engine**: Categorical attributes are automatically extracted to create real-time interactive filters.
- 📈 **Multi-Chart Analytics**: Generates minimum 3 interactive visualizations:
  - **Bar Chart**: Category distribution breakdown
  - **Area / Line Chart**: Metric trend progression
  - **Donut / Pie Chart**: Proportional share analysis
- 📌 **Executive KPI Cards**: Real-time summary statistics including total record counts, metric sums, averages, and filter ratios.
- 🤖 **20-Point AI Analytical Report**: Deep-dive insights generated by OpenAI GPT API explaining data distribution, key findings, and trends.

---

## 🛠️ Tech Stack

### Frontend
- **React.js**
- **Recharts** (Data Visualization)
- **Lucide React** (Modern Icons)
- **Axios** (HTTP API Requests)

### Backend
- **Python 3.10+**
- **FastAPI** (High-Performance API Framework)
- **Pandas & NumPy** (Data Processing & Aggregation)
- **OpenAI API** (AI Insight Generation)
- **Uvicorn** (ASGI Web Server)
